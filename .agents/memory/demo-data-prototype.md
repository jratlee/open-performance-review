name: Local-first demo prototype
description: Durable product boundary for the Is Harry Tired? prototype.
---

The public prototype should remain local-first and database-free until the source project explicitly calls for persistence. Its six-show dataset is illustrative, source links are outbound placeholders, and the UI must separate observable performance energy from any diagnosis of how Harry feels.

**Why:** The upstream repository intentionally uses demo records to exercise independent publication, evidence, result, and confidence rules without introducing accounts, secrets, or paid services.

**How to apply:** Preserve the fixed Anchor Moments, draft/publication boundary, and evidence-led language when extending the public app. Add editor/auth behavior as a separate scoped change.
